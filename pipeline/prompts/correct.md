# Bounded correction prompt

Read the source packet, original candidate, frozen contract, machine-validation report and adjudicated source-review findings.

Write a complete corrected Turtle file only in the assigned revised path. Preserve the original extraction and review reports. Correct unsupported claims, missing central facts, wrong roles and structural errors using only the frozen ontology and vocabulary. Retain conditions, exceptions and identity uncertainty.

Do not add ontology terms or silently turn a modelling limitation into a different historical meaning. Where the vocabulary is insufficient, use a source-supported note and record the gap. Do not treat every review opinion as a demonstrated error; follow the adjudicated correction scope.

Return a correction log by UID, including retained gaps and explicit unchanged records. Deterministic validation and expert review remain separate later gates.
