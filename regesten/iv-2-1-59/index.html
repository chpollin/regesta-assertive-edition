RI IV,2,1 n. 59(1143-1152) Februar 1Memmingen

Friedrich, Herzog (von Schwaben), wird als Zeuge in einer Urkunde Herzog Heinrichs (des Löwen) von Sachsen für das Stift Wilten genannt.

Aussagen

Der LLM-basierte Agent hat aus diesem Regest keine Aussage im Rahmen des Modells gewonnen.

Überlieferung Jordan, Urk. Heinrichs des Löwen no 17; vgl. Feldmann, Welf VI. Reg. 12.

Prüfverlauf der LLM-basierten Agenten
  • Befund Source document node without rdfs:label. Not a semantic defect.
  • Abwägung, nicht erforderlich The guidelines require an abstention file to contain the source document node typed crm:E31_Document; no label is required, and the reviewer itself calls it no semantic defect.
  • Lücke im Modell, Extraktion Attestation as witness of a charter has no role or act type. The charter of Herzog Heinrich (des Löwen) for Stift Wilten is mentioned without content, and the contract has no untyped charter-issuance act, so no factoid was recorded.
  • Lücke im Modell, Review An issued charter of a third party for a named recipient, without content, has no in-scope representation.
