Review history of the LLM-based agents
  • Finding The identifier carries a dagger (RI IV,2,1 n. †83), marking the charter as spurious. summary_plain does not state this, so the factoids correctly report only what the regest says, but a reader of the graph cannot see that the source charter is a forgery.
  • Finding The register candidate for Didius Julianus is typed "ort" in the packet, while the candidate types him crm:E21_Person. The regest's wording (seinem Vorgänger) supports a person; the register type is a register error, not an extraction error.
  • Finding Both parties carry rv:Kin, so the direction of descent (the family descends from Didius Julianus) is carried only by the qualifier "abstammende". This follows the guidelines.
  • Finding The right to bear arms has no right type in rv:RightTypes, so the grant carries no crm:E30_Right node and the content survives only in rf:qualifier.
  • Adjudication, recorded as a gap in the model summary_plain does not state the forgery, so the factoids correctly report the regest; the contract has no document-level authenticity marker.
  • Gap in the model, extraction No right type for a right of arms ('einen gekrönten schwarzen Adler im Wappen zu führen'); the RightGrant carries no E30 node and keeps the wording in rf:qualifier.
  • Gap in the model, extraction Descent of a family from an ancestor ('abstammende') is recorded as Kinship between the person and a group; the vocabulary has no descent type. 'seinem Vorgänger' (predecessor relation) not extracted.
  • Gap in the model, extraction The regest number carries a dagger (n. †83), marking the charter as spurious in the edition; the model has no place to carry the authenticity judgement, which lies outside summary_plain.
  • Gap in the model, review No document-level marker for a spurious or forged charter.
  • Gap in the model, review No right type for heraldic rights (Wappen).
  • Gap in the model, review No directed descent role; rv:Kin is symmetric.
  • Gap in the model, review Predecessor in office (Vorgänger) between rulers is not expressible as a relation.
